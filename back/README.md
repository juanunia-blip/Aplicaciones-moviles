# 🏨 Hotel Backend – App Hotel Popayán

Backend desarrollado en **Python con FastAPI** para la gestión de un sistema hotelero.
Este proyecto permite administrar habitaciones, reservas, servicios, lugares turísticos y usuarios con autenticación JWT.

---

## 🚀 Tecnologías utilizadas

- Python 3
- FastAPI
- SQLAlchemy
- Pydantic
- SQLite (para desarrollo)
- JWT (JSON Web Tokens)
- Uvicorn
- Git y GitHub

---

## 📁 Estructura del proyecto
El proyecto está organizado en módulos para facilitar su mantenimiento y escalabilidad.



## ⚙️ Instalación y ejecución

1. Clonar el repositorio
2. Crear entorno virtual
3. Instalar dependencias
4. Ejecutar el servidor con Uvicorn
